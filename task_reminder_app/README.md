# Task Reminder App (Dart - Async & Await)

## Project Overview
This project is a console-based Task Reminder application developed using the Dart programming language.  
The main objective of this project is to understand asynchronous programming concepts such as Future, async, and await.

The application simulates real-world operations like loading tasks and saving tasks with delays.

---

## Objectives
- To implement Dart fundamentals like classes, objects, and lists  
- To understand and apply asynchronous programming  
- To simulate real-world app behavior using async and await  

---

## Features
- Create a Task with:
  - Title
  - Description
  - Due Date  
- Load tasks asynchronously (simulated delay)  
- Add new tasks asynchronously  
- Display all tasks  

---

## Concepts Used
- Dart Basics:
  - Variables  
  - Functions  
  - Classes & Objects  
  - Lists  
- Asynchronous Programming:
  - Future  
  - async & await
